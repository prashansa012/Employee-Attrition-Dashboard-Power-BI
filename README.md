# Employee Attrition Analysis Dashboard

## Overview

Employee attrition is a critical HR metric that directly impacts organizational productivity, hiring costs, and workforce stability. This project presents an interactive Power BI dashboard designed to analyze employee attrition patterns and uncover key factors contributing to employee turnover.

The dashboard enables HR teams and business stakeholders to monitor workforce trends, identify high-risk employee groups, and support data-driven retention strategies.
## Project Objectives

- Analyze employee attrition trends across the organization.
- Identify departments and job roles with higher turnover rates.
- Understand the impact of age, gender, salary, education, and experience on attrition.
- Monitor key HR metrics through interactive visualizations.
- Provide actionable insights to improve employee retention.
